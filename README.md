## 🌟 核心功能特色

1. **题型 100% 对标真题规范**：
   * **全考点选择题特训**：纯选择题特训专攻，覆盖网络 58 题 + 数据库 49 题 + Linux 53 题（共 160 题），支持按考点分类刷题、关键词实时搜索、做题即判、详尽解析、标记疑难题与个人错题本管理；
   * **网络技术全真卷**：涵盖 OC-12 速率、双工带宽、CIDR 聚合、Cisco 路由器配置、DHCP 报文与 Wireshark 抓包十六进制分析；
   * **数据库技术全真卷**：涵盖 1NF~BCNF 规范化与候选码闭包求解、SQL Server 存储与索引、T-SQL 触发器编程、两阶段锁与日志检查点故障恢复；
   * **Linux 应用与开发全真卷**：涵盖 FHS 目录结构、Shell 脚本编程、文件权限（SUID/Sticky）、存储 LVM 扩容与挂载、进程与定时任务、GCC 编译链接、GDB 调试回溯堆栈、Makefile 构建与 Nginx 部署。
2. **双模式自如切换**：
   * 📝 **全真模考模式**：120 分钟倒计时、交卷前不剧透答案、一键自动评分并生成成绩诊断报告单与错题清单；
   * 💡 **逐题刷题模式**：即答即判，即刻查看官方考点解析与解题思路。
3. **智能容错自动判分**：填空与大题输入框自动忽略前后空格与大小写，支持等价指令模糊匹配。
4. **单文件纯静态**：无任何外部服务器依赖，支持暗黑/日间主题切换，做题进度自动存储在本地浏览器缓存。

## ⚙️ GitHub Pages 部署开启方法

若您是仓库管理员，只需在 GitHub 仓库中开启 Pages 服务：
1. 打开本仓库页面：[HookCola/ncre-mock-exam](https://github.com/HookCola/ncre-mock-exam)；
2. 点击上方 **Settings** -> 左侧菜单选择 **Pages**；
3. 在 **Build and deployment** 下方的 **Branch** 选择 `main` 分支，目录选择 `/ (root)`；
4. 点击 **Save** 保存，等待 1~2 分钟即可通过 `https://hookcola.github.io/ncre-mock-exam/` 访问。
